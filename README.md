# Cooking App

Мини‑приложение для поиска рецептов с локальной авторизацией и заметками. Всё работает в браузере без сервера.

## Возможности

- Каталог из 25 рецептов с карточками и эмодзи.
- Поиск по названию и ингредиентам.
- Заметки к рецептам и история поиска.
- Демо‑авторизация: регистрация и вход (данные хранятся в localStorage).

## Технологии

- HTML5, CSS3, Vanilla JS.
- GitHub Pages для хостинга.

## Как запустить

Проект уже размещён на GitHub Pages: [открыть сайт](https://vanus52.github.io/cooking-app).
